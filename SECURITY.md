# Security Policy

## Supported versions

Security fixes are applied to the latest revision of the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or leaked credential.
Use GitHub's private vulnerability reporting for this repository instead:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include the affected version, reproduction steps, and expected impact.

Never include production tokens, webhook payloads containing personal data, or
private keys in a report. Replace them with minimal synthetic examples.
